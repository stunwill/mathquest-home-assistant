# MathQuest v0.35.1

## Parent Dashboard Reliability Corrective Release

This release fixes the Parent Dashboard failing to render even while its backend requests succeed.

### Fixed

- Corrected inconsistent React hook ordering in Parent Learning Intelligence during the initial null-to-loaded data transition.
- Added explicit Parent Dashboard loading and error states so required bootstrap failures cannot leave an indefinite splash screen.
- Limited blocking startup data to the parent dashboard and worksheet settings.
- Backups and learning-intelligence enhancements now fail independently and show retryable inline errors.
- Preserved Home Assistant ingress, MathQuest JWT authentication, Parent Tests and all learner functionality.

### Ingress finding

MathQuest is configured with standard Home Assistant add-on ingress (`ingress: true`, `ingress_port: 8080`) and does not expose a `/ingress/validate_session` FastAPI route. The observed Home Assistant `/ingress/validate_session` 401 therefore is not generated by MathQuest application routing and was not the root cause identified for the Parent Dashboard render failure.

### Regression coverage

A frontend regression test now renders Parent Learning Intelligence first with no data and then with loaded data, reproducing the lifecycle that previously violated React hook ordering.
