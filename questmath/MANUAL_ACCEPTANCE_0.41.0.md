# MathQuest v0.41.0 Manual Acceptance

These checks require a real browser/device session. Do not mark them complete from unit tests, CSS inspection, emulation or CI alone.

## iPhone portrait

- [ ] Progress is understandable without parent assistance.
- [ ] Current learning priorities are obvious.
- [ ] Learning-state wording feels age appropriate for an 11-year-old Grade 5 learner.
- [ ] Recommendation explanations remain concise.
- [ ] No horizontal page overflow occurs.
- [ ] Home remains action-first.
- [ ] Continue Learning still outranks recommendations when unfinished work exists.
- [ ] Bottom navigation remains usable and Progress opens the learner-guidance section.
- [ ] No excessive vertical card density has returned.
- [ ] Learning-state labels and messages wrap cleanly.
- [ ] Optional learning detail expands and collapses without disrupting navigation.

## Learning guidance

- [ ] Practising state makes sense for current learning.
- [ ] Getting stronger is only shown when recent independent evidence is strong.
- [ ] Ready for a challenge reflects repeated independent success rather than one strong result.
- [ ] Supported success is presented as Building confidence, not failure.
- [ ] Review due reads as purposeful retrieval rather than remediation.
- [ ] Diagnostic recommendation explanation matches the actual diagnostic action.
- [ ] Prerequisite recommendation explanation matches the learning activity.
- [ ] Review recommendation explanation matches the actual spaced-review activity.
- [ ] No raw mastery percentage is exposed in the student's Best Next Step explanation.
- [ ] Technical misconception codes are not exposed to the student.
