# MathQuest v0.32.1, Worksheet Learning Quality Corrective Release

This corrective release preserves v0.32.0 Parent Learning Intelligence and focuses on real worksheet quality.

## Learner flow

- Immediate retry after an incorrect answer remains available.
- Math Mentor, hints and worked examples remain optional support.
- Existing misconception, prerequisite, spaced-retrieval and scoring evidence is preserved.

## Worked examples

- Worked examples now align more tightly to the current question family, operation or representation.
- Probability, fraction number-line, Measurement, Space and Statistics examples use relevant solving structures with different values.
- Alignment metadata supports regression testing without exposing the assessed answer.

## Difficulty quality

- Very simple arithmetic remains available for retrieval, confidence and prerequisite checks.
- When recent learner evidence supports progression, trivial arithmetic is limited to a small worksheet retrieval allowance.
- Questions are annotated as retrieval, instructional or challenge work for future adaptive composition improvements.

## Diversity and visuals

- Question-family diversity is re-checked after later adaptive difficulty transformations.
- Existing denominator-accurate fraction number lines and visual state safeguards remain in place.

## Compatibility

- No destructive database migration.
- Existing users, worksheets, attempts, progress, learning evidence, Parent Learning Intelligence and Parent Test isolation are preserved.
