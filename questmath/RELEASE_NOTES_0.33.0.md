# MathQuest 0.33.0: Adaptive Daily Learning

MathQuest now uses accumulated learner evidence to make daily sessions more purposeful. Practice questions are classified as current learning, consolidation, spaced review or limited challenge work, with progression driven by repeated independent success rather than isolated correct answers.

The adaptive engine slows progression when hints or Math Mentor support remain high, uses repeated misconception evidence to favour consolidation, and brings previously strong skills back for review when existing retention evidence says they are due. Parent Tests remain isolated from these decisions.

This release preserves the v0.32.3 method-first Math Mentor, Grade 5 Algebra variety, Visual Mathematics, retry-first tutoring, post-transform question-family diversity and Parent Learning Intelligence.
