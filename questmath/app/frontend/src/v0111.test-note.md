# v0.11.1 sidebar load regression scope

The v0.11.1 hotfix removes legacy version-label writes from v0.6-v0.9 enhancement scripts, coalesces whole-document MutationObserver callbacks through requestAnimationFrame, guards async enhancement requests against duplication, and prevents visual questions from being removed/reinserted on every DOM mutation.

Regression checks: login screen renders after an unauthenticated /api/me response; repeated DOM mutations do not cause version-label ping-pong; visual questions render once per current question; parent/student enhancement fetches cannot fan out while a prior fetch is still pending; observers disconnect on pagehide.
