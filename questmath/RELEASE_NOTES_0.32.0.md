# MathQuest 0.32.0: Parent Learning Intelligence

MathQuest 0.32.0 turns the learning evidence already collected by the app into a clearer parent-facing view of progress, independence, support needs, retention and next learning priorities.

## Highlights

- Plain-language parent learning summary based on real learner evidence.
- Skill-level mastery states: Secure, Developing, Needs Support, Review Due and Not Enough Evidence.
- Separate first-attempt, eventual and supported-success reporting so tutoring-assisted answers do not overstate mastery.
- Evidence-confidence labels based on the number of attempts supporting each judgement.
- Prioritised practice recommendations with clear reasons.
- Repeated misconception grouping and prerequisite-aware explanations.
- Retention and spaced-review visibility.
- Difficulty calibration that considers support dependency as well as accuracy.
- 7, 30 and 90-day progress comparisons.
- Responsive parent layouts for desktop, tablet, mobile and Home Assistant ingress.
- Parent Test evidence remains isolated from learner mastery, recommendations and retention.
- Frontend TypeScript configuration keeps explicit Node/Vite types and Bundler module resolution.

## Upgrade compatibility

- Existing users, worksheets, attempts, mastery evidence and parent-test records are preserved.
- No destructive database migration is introduced by this release.
- Existing Math Mentor, Visual Mathematics, tablet learner layouts and v0.30.1 corrective safeguards remain in place.
